RNF-001 — Compatibilidade com dispositivos móveis
O sistema deve possuir interface responsiva, permitindo sua utilização em smartphones, tablets e computadores.


RNF-002 — Usabilidade
O sistema deve possuir uma interface simples e intuitiva, permitindo que usuários com diferentes níveis de familiaridade com tecnologia realizem as operações principais sem necessidade de conhecimentos técnicos.

RNF-003 — Desempenho
O sistema deve apresentar tempo de resposta adequado nas operações principais, evitando interfaces excessivamente pesadas e mantendo boa utilização em dispositivos com recursos limitados.


RNF-004 — Persistência dos dados
O sistema deve armazenar de forma persistente os dados registrados, permitindo sua consulta posteriormente e evitando a perda das informações após o encerramento da aplicação.


RNF-005 — Segurança e controle de acesso
O sistema deve possuir mecanismo de autenticação e controle de acesso, restringindo o acesso às informações conforme o usuário autorizado.


RNF-006 — Evolução do sistema
A estrutura do sistema deve permitir a inclusão futura de novos módulos e funcionalidades sem exigir a reconstrução completa da aplicação.

RNF-007 — Manutenibilidade
O sistema deve possuir código e estrutura organizados, documentados e modularizados, facilitando sua manutenção, correção e evolução futuras.
