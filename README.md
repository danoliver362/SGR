# SGR - Sistema de Gestão para Relojoarias

## 📌 Sobre o Projeto

O SGR é um sistema desenvolvido para auxiliar no gerenciamento de relojoarias, organizando ordens de serviço, clientes e o fluxo de trabalho da oficina.

O projeto nasceu a partir da necessidade de melhorar a organização da relojoaria da minha família, reduzindo processos manuais e tornando o atendimento mais eficiente.

---

## 🎯 Objetivos

- Organizar Ordens de Serviço (OS);
- Controlar o status dos serviços;
- Cadastrar clientes e relógios;
- Facilitar a localização de relógios;
- Melhorar a organização da oficina;
- Reduzir erros operacionais.
